# The OmniFit Journal — post calendar

Cadence: one post every two weeks (scheduled drafts on the 1st and 15th of each
month). Each run takes the FIRST row whose status is `queued`, unless the owner
has asked for a different topic. Status values: `queued` → `draft (blog-NN)` →
`published YYYY-MM-DD`. Update this file in the same commit that publishes.

Every post pairs a physical stage of the OmniFit Method (Assess, Correct,
Build, Sustain) with a behavioral stage (Awareness, Regulation, Adaptation,
Integration). Titles are working titles; the run may sharpen them, but never
into an owned keyword (CANON KEYWORD OWNERSHIP).
